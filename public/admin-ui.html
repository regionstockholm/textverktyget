Användare

Konton ger endast åtkomst till verktyget, inte egna inställningar. Ta bort och skapa kontot igen för ett nytt lösenord. Befintliga textloggar behålls enligt lagringstiden.

Säkerhetskopiera användare

Hämta en säkerhetskopia innan databasen tas bort. Filen innehåller användarnamn och lösenordshashar, inte läsbara lösenord. Efter återställning fungerar samma lösenord igen. Inställningar och textloggar ingår inte.

Förvara filen säkert utanför applikationen. Återställning kräver en tom användarlista och avslutar alla gamla användarsessioner. Administratörens nyckel säkerhetskopieras inte.

Textlogg

Loggen sparar användarnamn, UTC-tid och inskickad text. Utan inloggning används default_user. Minsta lagringstid är 30 dagar. Äldre poster rensas automatiskt varje timme. Minskad lagringstid kan ta bort äldre poster permanent.

CSV innehåller känslig text. Exporterade filer omfattas inte av serverns automatiska rensning. Fält som kan tolkas som kalkylbladsformler får ett skyddande apostrofprefix.

Automatisk profilväxling (quality/balanced/stress)

Växlar profil efter belastning. Auto följer mätvärden, Manual låser vald profil. Dry run loggar förslag utan att tillämpa dem.

1) Driftläge: Auto enabled slår på av/på hela funktionen. Mode styr om växling sker automatiskt eller manuellt. Manual profile används endast när Mode = manual. Dry run testar logik utan att ändra profil.

2) Utvärderingsintervall: Styr hur ofta systemet räknar på belastning och hur länge ett mätfönster är aktivt.

3) Växlingsregler: Definierar när profilbyte får ske baserat på antal mätpunkter och antal på varandra följande signaler.
